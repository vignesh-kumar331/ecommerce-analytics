## Methodology

This analysis was conducted using basic spreadsheet techniques in Microsoft Excel:

- **Data Source:** Single CSV file with 6,000 order records
- **Analysis Period:** July 2024 – December 2025 (18 months)
- **Metrics Calculated:** Total Revenue, Order Count, Average Order Value, Monthly Trends, Category Performance, Repeat Purchase Rate, Churn Identification
- **Churn Definition:** Customers whose most recent order was more than 90 days before the most recent order date in the dataset
- **Tools Used:** Excel formulas (SUM, COUNTA, AVERAGE, COUNTIF, MAX, TEXT, IF), Pivot Tables, Line Charts, Bar Charts
