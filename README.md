# E-Commerce Sales & Customer Retention Analytics

A beginner-level data analytics project analyzing 18 months of e-commerce sales data to understand revenue performance, customer buying patterns, and customer retention.

## Dataset

- **6,000 orders** across **2,270 unique customers**
- **18 months** of data (July 2024 – December 2025)
- **5 product categories:** Electronics, Clothing, Home & Kitchen, Beauty, Sports

## Files

| File | Description |
|------|-------------|
| `orders.csv` | Main sales dataset |
| `EXCEL_ANALYSIS_GUIDE.md` | Step-by-step Excel instructions with formulas |
| `SUMMARY_REPORT_TEMPLATE.md` | Fill-in-the-blank report template |
| `generate_data.py` | Python script to regenerate the dataset |

## Analysis Steps

1. Load and clean the data
2. Calculate total revenue, orders, and average order value
3. Analyze monthly revenue trends
4. Analyze revenue by product category
5. Calculate repeat purchase rate
6. Identify churned customers (90+ days inactive)
7. Build a dashboard with KPI cards and charts
8. Write a summary report with recommendations

## Tools Required

- Microsoft Excel or Google Sheets
- No programming or advanced analytics required

## How to Use

1. Open `orders.csv` in Excel (Data → From Text/CSV)
2. Follow the step-by-step instructions in `EXCEL_ANALYSIS_GUIDE.md`
3. Use `SUMMARY_REPORT_TEMPLATE.md` to write your findings

## Expected Learning Outcome

Demonstrates the basic Data Analyst workflow:

**Collect Data → Clean Data → Calculate Metrics → Analyze Data → Create Charts → Find Insights → Make Recommendations**
